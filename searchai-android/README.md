# SearchAI Android

Phone-first SearchAI MVP. Enter what you want to find, tap Search Everywhere, then open the selected sources in SearchAI's built-in browser.

## Safety
CAPTCHA and identity verification are never automated or bypassed. SearchAI pauses for the person to complete them. The app researches and compares; it does not automatically buy, bid, pay, message, or delete.

## Build
GitHub Actions runs unit tests and builds `app-debug.apk`. The uploaded artifact is named `SearchAI-Android-APK`.
